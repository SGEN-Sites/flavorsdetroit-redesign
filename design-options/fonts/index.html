Design options · font pairings

Headline fonts closer to the sign

The inline face used for the accent words is gone. Below are four pairings drawn from fonts measured against the real Flavors Detroit lettering on the logo, each shown on a slice of the site in the new black, blue and white palette, with the current pairing at the end for comparison.

Every font here is free to use and to host with the site (SIL Open Font License), so nothing is loaded from a third party once a pairing is chosen.

Which font matches the logo

Measured, not eyeballed: each of the 14 letters of "FLAVORS DETROIT" was cut out of the logo file and compared pixel by pixel with the same letter set in 72 candidate fonts at the same height (overlap 1.0 = identical).

  1. Jockey One: closest overall shape (overlap 0.834) and the same letter widths as the logo (1.01×); softly rounded corners.
  2. Teko 600: 0.828, a touch wider (1.04×), rounded corners.
  3. Staatliches: 0.818, but it has no lowercase, which would make every headline look all caps.
  4. Khand 700: 0.816, same width (0.99×), slightly lighter.
  5. Agdasima 700: 0.809, and the only one in the top ten with the logo's octagonal, cut corners on O, D, R and S.
  6. Rajdhani 700: 0.810, cut corners too, but wider (1.12×) and lighter.

The current headline font (Big Shoulders Display) scores 0.745 and is 14% narrower than the sign's letters.

The logo lettering (top left) beside the closest fonts, all at the same letter height. Full scores for all 72 fonts: logo-match-ranking.json.

A · Jockey One + BarlowRecommended

The closest measured match to the sign: the same letter widths and the same heavy weight, with softer corners, and it stays readable in long headlines. Barlow, drawn from highway and road signs, keeps paragraphs easy to read and suits a roadside marquee.
