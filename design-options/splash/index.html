How it would ship

The same rules apply whichever concept is picked.

Length
About 2.3 seconds from the first frame to the page (2.28 to 2.30 seconds, depending on the concept). It starts as soon as the logo has loaded; if that takes longer than 0.6 seconds, the page shows straight away instead, so the splash never holds anyone up.
Once per session
It plays on the first page a visitor opens and is then remembered for the rest of that browser session, so later pages and reloads open directly. It plays again on their next visit.
Skip
A click, tap, scroll or any key fades it out in 0.2 seconds. The splash catches that tap itself, so it never lands on a link underneath.
Reduced motion
Visitors whose device is set to reduce motion never see it; the page shows directly. The same goes when JavaScript is off, and a 4-second fail-safe hands over the page if the script ever stalls. The switch at the top previews this.
Age gate
On a first visit the splash plays first, then hands off to the age gate: the gate fades in over the same black instead of the page, and the page stays locked behind it until the visitor answers. Returning visitors, whose answer is kept for 30 days, go straight from the splash to the page.
With the hero
The home page hero already switches its own sign on once per session. If Sign ignition or Night drive is picked, the splash takes over that moment, so the bulbs never light up twice.
Build
Plain HTML, CSS and a small script, no libraries. It animates only transform, opacity and filter, and sits fixed above the page, so the page layout never moves (layout shift measured at 0 in every demo). It reuses the site's own logo files and fonts.

Demos only: nothing on this page is wired into the site yet. The black block behind each splash stands in for the home page.
